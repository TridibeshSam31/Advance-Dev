HTML is not a programming language.
It’s a markup language that describes structure, meaning, and relationships of content.


HTML does four critical jobs:

Defines document structure
Provides semantic meaning
Enables accessibility
Connects with CSS, JS, SEO, and browsers


Anatomy of an HTML Tag
<tagname attribute="value">content</tagname>

Types of tags
1.Paired tags
<p>Hello</p>

2.Void / self-closing tags
<img />
<input />
<br />


3.Global Attributes (MOST IMPORTANT — Learn Once, Use Everywhere)
These work on almost every element.

Some of the core global Attributes
| Attribute         | Why it matters                             |
| ----------------- | ------------------------------------------ |
| `id`              | Unique identifier (CSS, JS, accessibility) |
| `class`           | Grouping + styling                         |
| `style`           | Inline CSS (use sparingly)                 |
| `title`           | Tooltip + accessibility                    |
| `hidden`          | Removes element from layout                |
| `tabindex`        | Keyboard navigation                        |
| `contenteditable` | Editable content                           |
| `draggable`       | Drag & drop                                |
| `spellcheck`      | Text validation                            |


Data Attributes (VERY IMPORTANT)
<button data-user-id="42">Click</button>

Access in JS:
element.dataset.userId

11. Accessibility


ARIA Attributes (Use only when needed)
ARIA = Accessible Rich Internet Applications


Screen readers aur assistive tech ko batata hai:

ye element kya hai

kaise behave karta hai

abhi kya state me hai

Browser ko nahi — insaan (assistive tech user) ko help karta hai.

ARIA KI ZAROORAT KYON PADTI HAI?

HTML ke paas fixed semantics hote hain.
Par modern apps me hum banate hain:

custom dropdowns

modals

tabs

sliders

toasts

Ye sab div + JS se bante hain → browser ko samajh nahi aata.

👉 ARIA bolta hai:

“Bhai ye div actually button hai”
“Ye modal open ho chuka hai”
“Ye input error state me hai”



<button aria-label="Close modal">X</button>

key ARIA:

aria-label
aria-hidden
role
aria-live

🚫 Don’t abuse ARIA. Semantic HTML > ARIA.
