The Call Stack is a LIFO execution structure that tracks where the JavaScript engine currently is and what it must return to next.

It answers exactly two questions:
What function is running right now?
What should run after this finishes?

That’s it.

EVENT LOOPSSSSSSSSSSSSSSSSSSSSSSSSSSSSSSS

Myth: Event loop runs async code 
Truth: Event loop decides WHEN callbacks are allowed to touch the call stack

The event loop never executes code.
It only pushes callbacks onto the call stack when the stack is empty.


If the call stack is NOT empty, the event loop is POWERLESS

No promises.
No timers.
No I/O.
No mercy.

while (true) {}

Event loop = dead spectator.

What the Event Loop actually is (implementation-level)
At the lowest level, the event loop is basically:
while (program_is_alive) {
  run_one_phase();
  drain_microtasks();
}

That’s it.
No magic. No async fairy.


Event Loop Phases (Node)

Timers
I/O callbacks
Idle, prepare
Poll
Check
Close callbacks

After EVERY phase:
process.nextTick queue is drained
Microtask queue (Promise.then) is drained

what is timer phase 
Handles:

setTimeout
setInterval

setTimeout(fn, 0) does NOT mean “run immediately”

It means:

“Eligible to run in timers phase after delay AND after stack is empty”

I/O callbacks
Handles:

TCP errors
Some network callbacks
Deferred system callbacks

⚠️ Not:
fs.readFile completion (that goes via poll)


Idle / Prepare
Internal Node stuff


Poll phase

This is the heart.
Poll phase does:
Execute I/O callbacks (fs, network)
If nothing to do → wait
If timers are due → move to timers phase

This is where Node:
Sleeps
Wakes up
Decides next move

👉 If poll queue is empty AND no timers are due → Node waits


Check phase

Handles:
setImmediate

setImmediate(() => console.log("immediate"));

Always runs after poll, before timers (next loop).


Close callbacks

Handles:

socket.on("close")
Cleanup logic

Why CPU-heavy code kills Node
app.get("/", (req, res) => {
  for (let i = 0; i < 1e10; i++) {}
  res.send("done");
});
What happens?

That loop runs on main thread

Event loop cannot rotate

No new requests handled

Load balancer thinks instance is dead

Users see timeouts

👉 Node cannot:

Accept connections

Respond to health checks

Execute callbacks

💀 One user = entire server down
