Exit Codes used while Bash Scripting ??
Every command returns:

0 = success
non-zero = failure

Example:

npm install
echo $?

Output:

0

Success.

Use:

if [ $? -eq 0 ]
then
   echo "Success"
else
   echo "Failed"
fi

DevOps engineers use this constantly.
