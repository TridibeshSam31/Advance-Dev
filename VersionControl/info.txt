What is the difference between git add and git commit ??

git add = prepare changes

git commit = save snapshot permanently




What Actually Is A Commit?



Commit sirf message nahi hota.

Commit contains:

Files snapshot
Author
Date
Commit Message
Commit Hash

Example:

git log

Output:

e8a4c7d

Ye hash hai.

Unique ID.

Git internally commits ko linked list jaisa maintain karta hai.

A → B → C → D

Current commit pe HEAD pointer hota hai.

A → B → C → D (HEAD)

HEAD = current location.





Branching in Git 

Maan le production app chal rahi hai.

main

Ab tu login feature banana chahta hai.

Direct main me code karega?

Nahi.

Branch banaega.

git checkout -b feature/login

Internally:

main
  │
  └── feature/login

Ab tu kuch bhi tod-phod kar sakta hai.

Because of this main branch remains safe 



What is Merge ??


Feature complete.

git checkout main
git merge feature/login

Git dono histories combine karta hai.

Before:

A → B

      C → D

After:

A → B → E
       ↗
     C → D

E = Merge Commit.
