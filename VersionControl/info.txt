What is the difference between git add and git commit ??

git add = prepare changes

git commit = save snapshot permanently




What Actually Is A Commit?



Commit sirf message nahi hota.

Commit contains:

Files snapshot
Author
Date
Commit Message
Commit Hash

Example:

git log

Output:

e8a4c7d

Ye hash hai.

Unique ID.

Git internally commits ko linked list jaisa maintain karta hai.

A → B → C → D

Current commit pe HEAD pointer hota hai.

A → B → C → D (HEAD)

HEAD = current location.





Branching in Git 

Maan le production app chal rahi hai.

main

Ab tu login feature banana chahta hai.

Direct main me code karega?

Nahi.

Branch banaega.

git checkout -b feature/login

Internally:

main
  │
  └── feature/login

Ab tu kuch bhi tod-phod kar sakta hai.

Because of this main branch remains safe 



What is Merge ??


Feature complete.

git checkout main
git merge feature/login

Git dono histories combine karta hai.

Before:

A → B

      C → D

After:

A → B → E
       ↗
     C → D

E = Merge Commit.

what is Rebase ??

Suppose:

Main:

A → B → C

Feature:

A → B → D → E

Now main updated:

A → B → C → F

Rebase:

git rebase main

Result:

A → B → C → F → D → E

History linear.

Cleaner.

Companies prefer rebase workflow.



what is Stash ???

Manager:

Urgent bug fix karo

Tu half-done feature pe hai.

Commit nahi karna.

Use:

git stash

Git temporary drawer me changes rakh deta hai.

Drawer

Baad me:

git stash pop

Restore.



what is Reset ????


Danger Zone.

git reset --soft HEAD~1

Remove commit.

Keep code.

git reset --hard HEAD~1

Remove commit.

Remove code.

Everything gone.




what is Revert

Safer than reset.

git revert hash

Instead of deleting history:

A → B → C → D

Git creates:

A → B → C → D → E

E = reverse of D.

Production standard.
